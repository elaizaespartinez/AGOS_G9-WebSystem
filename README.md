# _G9-WebSystem
Disaster Management Website 

## How to run

Open two terminals.

### Terminal 1: Server

```powershell
cd "C:\Users\YourName\Projects\_G9-WebSystem\server"
npm install
npm start
```

### Terminal 2: Client

```powershell
cd "C:\Users\YourName\Projects\_G9-WebSystem\client"
npm.cmd install
npm.cmd run dev
```
